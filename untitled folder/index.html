Highest-Yield Decision Rules

Labels available: supervised learning. Categories = classification; numbers = regression.

No labels: unsupervised learning, clustering, anomaly detection, autoencoders.

Change tone/format/length cheaply: prompt engineering first.

Need current/private facts: RAG or Bedrock Knowledge Bases, not fine-tuning.

Build GenAI app quickly: Bedrock. Build/custom train ML lifecycle: SageMaker AI.

Fairness/explainability: balanced data, bias checks, Clarify, Model Cards, human review.

Security: IAM least privilege, CloudTrail audit, KMS encryption, PrivateLink, Macie, Artifact/Audit Manager.

Prompt, RAG, Fine-Tuning, Pre-Training

Prompt engineering: fastest and cheapest for style, format, language, tone, examples, and output limits.

RAG: use external knowledge. Best for changing facts, policies, manuals, FAQs, and private company documents.

Fine-tuning: use labeled prompt/completion examples to specialize behavior.

Continued pre-training: use unlabeled domain data to add specialized knowledge.

Pre-training from scratch: highest cost, highest effort, highest customer responsibility.

Responsible AI And Security

Bias/fairness: representative data, imbalance detection, bias metrics, human review.

Explainability: PDPs, feature attribution, Clarify, interpretable models.

Transparency: Model Cards, documented limits, intended use, datasets, evaluation results.

Security: IAM policies, service roles, KMS, PrivateLink, CloudTrail, CloudWatch, Macie.

Governance: data retention, data residency, compliance evidence, Audit Manager, Artifact.

Metrics And Model Terms

Accuracy: overall correct classifications. Weak when classes are imbalanced.

Precision: reduce false positives. Recall: reduce false negatives. F1: balance both.

Regression: RMSE/MSE/R-squared for numeric predictions.

Text generation: BLEU/ROUGE/BERTScore plus human evaluation.

Latency: real-time user experience. Throughput/cost: operational efficiency.

Business: conversion rate, cost per conversation, AHT, ticket reduction, revenue impact.

Last-Minute Trap Pairs

Transcribe: speech-to-text. Translate: language translation.

Q Business: employee business assistant. Q Developer: developer coding assistant.
