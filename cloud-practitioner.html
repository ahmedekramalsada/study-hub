The Solver Rules

Least operational overhead: choose managed, serverless, automated. RDS over database on EC2, Lambda/Fargate over EC2, Athena over running analytics servers.

Most cost-effective: choose based on workload. Short/unpredictable = On-Demand. Steady 1/3 years = Reserved or Savings Plans. Interruptible = Spot. Archive = Glacier.

Most secure: IAM roles, least privilege, MFA, encryption, private connectivity, no hardcoded keys, no root daily use.

High availability: Multi-AZ, Auto Scaling, Load Balancer, multiple AZs. Disaster recovery/global isolation = multiple Regions.

Hybrid/on-premises: VPN or Direct Connect for connectivity, Storage Gateway for local access to cloud storage, Snow Family for offline transfer, Outposts for AWS on-prem.

Multiple response: if the prompt says choose two, both answers must be right. One right option is still wrong on the real exam.

Security And IAM: The Highest-Yield Section

Shared responsibility

AWS: data centers, hardware, physical network, hypervisor, managed-service infrastructure.

Customer: data, IAM, encryption choice, security groups/NACLs, application code, EC2 guest OS.

EC2: customer patches OS. RDS: AWS patches host OS/database platform. Lambda: customer owns code/config.

Identity choices

IAM user: person/service identity inside one account.

IAM role: temporary credentials; best for EC2/Lambda/service access.

IAM policy: JSON permissions; least privilege.

IAM Identity Center: workforce SSO across AWS accounts and apps.

Cognito: sign-up/sign-in for your application users.

Security service chooser

Audit API calls = CloudTrail.

Resource config/compliance = AWS Config.

Threat detection = GuardDuty.

Vulnerability scan = Inspector.

PII/sensitive data in S3 = Macie.

Compliance reports = Artifact.

Web attack SQLi/XSS = WAF. DDoS = Shield.

S3 And Storage Patterns

S3 Standard: frequent access, multi-AZ durability/availability.

S3 Standard-IA: infrequent access, still multi-AZ.

S3 One Zone-IA: cheaper, one AZ, re-creatable infrequent data.

S3 Glacier Instant Retrieval: archive with milliseconds access.

Glacier Flexible / Deep Archive: lowest-cost archive, retrieval takes minutes to hours.

Intelligent-Tiering: unknown/changing access patterns.

Versioning: protect from overwrite/delete. Lifecycle = move/delete automatically. Replication = copy across buckets/Regions. Transfer Acceleration = faster uploads over distance.

Pricing And Billing Patterns

On-Demand: short-term, unpredictable, cannot be interrupted.

Reserved Instance: steady 1-year/3-year instance usage. Standard = biggest RI discount; Convertible = flexibility.

Savings Plans: commit dollars/hour; Compute Savings Plans are flexible across EC2, Fargate, Lambda.

Spot: up to large discounts, interruptible; batch, CI/CD, simulation, fault-tolerant jobs.

Dedicated Host: physical server for licensing/compliance. Capacity Reservation = capacity guarantee, no discount by itself.

Tools: Pricing Calculator = estimate before use. Cost Explorer = history/forecast. Budgets = alerts. CUR = detailed raw report. Compute Optimizer = rightsizing.

Cloud Concepts, CAF, Well-Architected

Cloud benefits: trade fixed expense for variable expense, stop guessing capacity, increase speed/agility, go global in minutes, benefit from economies of scale.

Elasticity: automatically add/remove resources with demand. Scalability: handle growth. High availability: keep running through failures.

Well-Architected pillars: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability.

CAF perspectives: Business, People, Governance, Platform, Security, Operations. People includes cloud fluency. Governance includes risk/portfolio. Business includes strategy/value.

Migration, Hybrid, And Governance

Application Discovery Service: collect on-premises server usage/configuration for migration planning.

Application Migration Service: lift-and-shift servers to AWS.

DMS: migrate databases. SCT: convert database schema.

DataSync: online data transfer. Transfer Family: SFTP/FTPS/FTP to S3/EFS.

Snow Family: offline large transfer or edge/disconnected processing.

Outposts: AWS infrastructure on-premises. Local Zones: low latency near cities. Wavelength: 5G edge.

Organizations: multi-account and consolidated billing. Control Tower: landing zone. Service Catalog: approved products/templates.

Multiple-Answer Patterns Worth Memorizing

EC2 rightsizing: Cost Explorer + Compute Optimizer.

Trusted Advisor benefits: cost optimization + security/performance/fault tolerance/service quota checks.

Discover, transform, visualize data: Glue + QuickSight.

Budget threshold notification: AWS Budgets + CloudWatch/SNS-style notification path.

Customer shared responsibilities: IAM/security groups/data classification/encryption choices/EC2 OS patching.

Well-Architected pillars: choose from the exact six names only; high availability and scalability are concepts, not pillar names.

Agility: quick resource implementation + quick experimentation.

Elasticity: right-size/add/remove resources as demand changes.

Last-Minute Trap Pairs

CloudWatch: metrics/logs/alarms. CloudTrail: API audit. Config: resource configuration.

Security Group: stateful resource firewall. NACL: stateless subnet firewall.

Route 53: DNS. CloudFront: CDN. Global Accelerator: network acceleration.

RDS Multi-AZ: failover. Read replica: read scaling.

EBS snapshot: backup. AMI: launchable EC2 image.

Artifact: AWS compliance docs. Audit Manager: collect evidence for audits.

Personal Health Dashboard: your resources. Service Health Dashboard: regional AWS service status.

Inbound data: usually free. Outbound/cross-Region: usually charged.

Root user: only account-level tasks, protect with MFA, no access keys.
